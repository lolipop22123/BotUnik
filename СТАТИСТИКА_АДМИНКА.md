# 📊 Статистика бота в админ панели

## ✅ Что реализовано

✅ Общая статистика бота
✅ Детальная статистика
✅ Статистика пользователей (всего, новые за день/неделю/месяц)
✅ Статистика платежей (количество, суммы)
✅ Статистика подписок (активные, истекшие)
✅ Статистика медиа (шрифты, музыка)
✅ Автообновление в реальном времени

## 📊 Метрики статистики

### 👥 Пользователи
- **Всего** - общее количество зарегистрированных
- **За сегодня** - новых пользователей сегодня
- **За неделю** - новых за последние 7 дней
- **За месяц** - новых за последние 30 дней

### 💰 Финансы
- **Всего платежей** - количество обработанных инвойсов
- **Оплачено** - количество успешных платежей
- **Сумма** - общая сумма всех платежей в USD

### 📝 Подписки
- **Всего подписок** - количество записей в таблице
- **Активных** - подписки с датой > текущей
- **Истекших** - подписки с датой ≤ текущей

### 🎬 Медиа
- **Шрифтов** - количество загруженных шрифтов
- **Музыки** - количество загруженных треков

---

## 💵 Детальная статистика - Финансы

### По периодам:
- **Сегодня** - сумма платежей за текущий день
- **Вчера** - сумма за вчерашний день
- **За неделю** - сумма за 7 дней
- **За месяц** - сумма за 30 дней

### Платежи (количество):
- Количество успешных платежей за каждый период

---

## 👤 Детальная статистика - Пользователи

### Активность:
- **Новых сегодня** - зарегистрировались сегодня
- **Новых вчера** - зарегистрировались вчера
- **С подпиской** - имеют запись в таблице subscriptions
- **Без подписки** - не имеют подписки

---

## 📝 Детальная статистика - Подписки

### Истечение:
- **Истекает сегодня** - подписки заканчиваются сегодня
- **Истекает за неделю** - истекут в ближайшие 7 дней
- **Средняя длительность** - средняя продолжительность подписки

## 🔧 Технические детали

### API функции статистики:

```python
# Пользователи
await db.count_users()                    # Всего
await db.count_users_by_period(days=0)    # За сегодня
await db.count_users_by_period(days=7)    # За неделю
await db.count_users_by_period(days=30)   # За месяц

# Платежи
await db.get_invoice_statistics()         # Общая статистика
await db.get_amount_by_period(days=0)     # Сумма за сегодня
await db.count_invoices_by_period(days=7) # Количество за неделю

# Подписки
await db.get_subscription_statistics()    # Общая статистика
await db.count_expiring_subscriptions(7)  # Истекают за 7 дней
await db.get_avg_subscription_duration()  # Средняя длительность

# Медиа
len(await db.get_all_fonts())            # Количество шрифтов
len(await db.get_all_music())            # Количество музыки
```

### Для принятия решений:
- 📈 Видно рост пользователей

- 📉 Можно отследить снижение активности

- Когда делать рассылки (когда больше новых пользователей)
