## 1. 💰 Система пополнения через CryptoBot

### ✅ Что работает:
- Ввод суммы пополнения
- Создание инвойса через CryptoBot API
- Выдача ссылки на оплату пользователю
- **Автоматическая проверка в фоне** (каждые 10 сек)
- **Автоматическое зачисление** при оплате
- **Автоотмена** через 5 минут если не оплачено
- Уведомления пользователю
- Защита от повторного зачисления

### 📁 Файлы:
- `config.py` - добавлен CRYPTO_BOT_TOKEN
- `handlers/User/profile.py` - вся логика пополнения
- `handlers/User/states.py` - PaymentStates
- `database/user.py` - add_balance(), is_invoice_processed(), mark_invoice_processed()
- `create_tables.py` - таблица processed_invoices

### 📖 Документация:
- Автоматическая проверка и зачисление
- Таймаут 5 минут
- Защита от дублей

## 📊 Базы данных

### Таблицы:

## 🚀 Как запустить все

### Шаг 1: Настроить .env
```env
BOT_TOKEN=ваш_токен_бота
ADMIN_ID=ваш_telegram_id
CRYPTO_BOT_TOKEN=ваш_crypto_bot_token
POSTGRES_DB=botUnik
POSTGRES_USER=postgres
POSTGRES_PASSWORD=1111
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
```

### Шаг 2: Создать таблицы
```bash
python create_tables.py
```

### Шаг 3: Установить зависимости
```bash
pip install -r requirements.txt
```

### Шаг 4: Создать папки
```bash
mkdir fonts
mkdir music
mkdir images
```

### Шаг 5: Запустить бота
```bash
python run.py
```
