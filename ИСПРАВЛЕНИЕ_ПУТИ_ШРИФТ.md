# ✅ ИСПРАВЛЕНИЕ ПУТИ К ШРИФТУ

## 🔍 Проблема
В логах видно что субтитры работают, но FFmpeg не может найти шрифт:

```
DEBUG combined_filter (chunk 1): drawtext=textfile="C:/Users/USER/AppData/Local/Temp/tmplfuqnnbt.txt":fontfile="fonts/Literal-Bold.ttf":...
```

**Проблема:** Путь к шрифту `fonts/Literal-Bold.ttf` - **относительный**, а FFmpeg требует **абсолютный путь**.

## ✅ Что исправлено

### 1️⃣ Преобразование относительного пути в абсолютный
```python
# Преобразуем относительный путь в абсолютный
font_path = font['file_path']
if not os.path.isabs(font_path):
    # Если путь относительный, делаем его абсолютным относительно корня проекта
    font_path = os.path.abspath(font_path)
```

### 2️⃣ Проверка существования файла шрифта
```python
# Проверяем существование файла шрифта
if not os.path.exists(font_path):
    await callback.answer(f"❌ Файл шрифта не найден: {font_path}", show_alert=True)
    return
```

### 3️⃣ Добавлена отладочная информация
```python
# DEBUG: выводим информацию о путях
print(f"🔤 Шрифт: {font_path}")
print(f"📝 Текст файл: {text_file}")
print(f"🔤 Экранированный шрифт: {font_path_escaped}")
```
